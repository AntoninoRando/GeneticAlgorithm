Concepts

Glossary

Every term used in the guide, the code and the thesis, in alphabetical order.

Access point
The satellite overhead that receives a ground user's job and decides where it runs.
Arity
Number of children of an operator: 2 for ADD, 1 for NEG, 0 for a terminal.
Baseline
A simple hand-written rule (FCFS, shortest job first, …) run through the same decoder, used to judge whether GP helps.
Bloat
GP trees growing larger over generations without getting better. Controlled here by the depth cap and hoist. Theory §6
Closure
The requirement that every operator accepts any value its children can produce. It is why division is "protected". GP basics
Clone retries
Option that re-mutates an offspring when it is structurally identical to a parent or an elite.
Completion ratio \(C\)
Share of the snapshot's jobs that the schedule places. Maximised.
Convergence threshold
Number of generations without a new best fitness after which main.py switches to the next world (default 10).
Crossover
Making offspring by swapping randomly chosen subtrees between two parents.
Decoder (greedy)
The fixed procedure that turns a tree into a schedule by repeatedly committing the feasible (job, satellite) pair with the highest score. Decoder & fitness
Depth
Longest root-to-leaf path in a tree, counted in edges. A single terminal has depth 0.
Diversity (structural)
Share of distinct trees in the population: 1.0 means all different, \(1/N\) means all clones.
Demo mode
main.py --demo (or ./run demo): trains on synthetic worlds instead of the real data, to show or try the program without the simulator's log. Its numbers mean nothing. Giving a demo
Depth-aware operators
Opt-in crossover and mutation that choose where to cut and how much to grow so that the result always fits under the depth cap. The default operators build the tree first and, if it is too deep, return a copy of the parent. See one generation.
Elitism
Copying the best individuals (2 here) unchanged into the next generation.
Fitness
One number per individual, higher is better: \(0.6\,C - 0.25\,\hat R - 0.15\,\hat{\mathcal E}\). Only comparable within one population. Details
Full method
Random tree construction where every leaf is at the target depth.
Function set
The operators GP may use: ADD SUB MUL DIV MAX MIN NEG ABS INV.
Generation
One round of evaluate → select → breed.
Genetic programming (GP)
Evolutionary search over programs, here formulas stored as trees (Koza).
GPHH
Genetic programming hyper-heuristic: GP used to evolve heuristics (here, scheduling rules).
Grow method
Random tree construction where branches may stop early. Biased here toward operators near the root.
Height (of a node)
The depth of the subtree below a node: 0 for a leaf. A node's depth plus its height is at most the depth of the whole tree.
Hoist mutation
Replacing a tree with one of its own subtrees. Shrinks trees.
Hyper-heuristic
A method that searches over heuristics instead of over solutions.
Individual
One candidate solution: here a GPIndividual with a tree, a fitness and an id.
LEO
Low Earth orbit, a few hundred kilometres up. Satellites there move fast relative to the ground.
List scheduling
The classic rule for several identical machines: take jobs from a priority list and give each one to the machine that becomes free first. The earliest-free tie-break makes a job-only formula behave this way.
Mutation
Random edits: redraw a terminal, swap an operator, or regrow a subtree. Rate 0.08 per node.
Normalisation (min-max)
Rescaling a value to [0, 1] using the population's minimum and maximum. The default for the two cost terms of the fitness; see also fixed-bound normalisation.
Normalisation (fixed-bound)
Rescaling a value to [0, 1] by dividing it by a bound that depends on the world only (\(R^{\max}\), \(\mathcal{E}^{\max}\)), not on the other individuals. Opt-in with --fixed-bounds. The fitness then means the same thing in every generation.
OpenMP
C++ compiler extension for parallel loops (#pragma omp parallel for). Used for evaluation and breeding.
operationalUntil (sunset)
Minute after which a satellite can no longer serve the user. No job may finish later.
Pareto optimal
A solution that no other solution beats on every objective at once.
Poisson process
A model of random arrivals in which the gaps between consecutive arrivals are independent and exponentially distributed; on average \(\lambda\) arrivals per unit of time. Used only by the synthetic demo data.
Population
The set of individuals in one generation (100 by default).
Priority function / score
What a tree computes for a (job, satellite) pair. Higher means "schedule first".
Protected division
\(x/y\), but 0 when \(|y| < 10^{-9}\). Printed as /?.
pybind11
C++ library that exposes C++ classes to Python. Used in bindings.cpp.
Ramped half-and-half
Initialisation where half the trees use full and half use grow, over a range of depths.
Rejection penalty
A fixed cost charged for a job that is not scheduled, so that leaving a job out is never cheaper than scheduling it late. With --fixed-bounds an unscheduled job counts as the worst possible response time, \(R^{\max}\).
Registry (terminal)
The list of 18 terminals with their accessor functions (registry.h).
Response time \(R\)
Completion minute minus arrival minute, averaged over scheduled jobs. Minimised.
SEC
Satellite edge computing: running computation on satellites.
Seed
Starting value of the random generator. The same seed gives the same run (--seed).
Selection pressure
How strongly selection favours the best individuals. Grows with tournament size. Theory §4
SEN
Satellite edge node: a satellite that runs jobs.
Simplification
Exact algebraic clean-up after mutation, such as \(\text{NEG}(\text{NEG}(x)) \to x\).
Snapshot
A frozen picture of the world (satellites + waiting jobs) at one minute \(\tau\). SimulationSnapshot in C++.
Takeover time
Generations that selection alone needs to fill the population with copies of the best individual.
Terminal
A leaf of the tree: an input such as job.executionTime.
Terminal weighting
Option that makes mutation favour terminals common in the best trees. Theory §7
Tie-break
What decides between two (job, satellite) pairs with exactly the same score. Default: lowest job index, then lowest satellite index. With --earliest-free-tie-break: the pair that can start first. See decoder.
Tournament selection
Pick \(k\) individuals at random and keep the fittest as a parent. \(k = 5\) here.
World
One 10-minute window of the simulator log, about 100 jobs. 30 worlds in total. Data pipeline
